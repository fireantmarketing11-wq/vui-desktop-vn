# Vui Desktop VN

Ứng dụng desktop đơn giản bằng Tkinter: gồm 2 tab — "Emoji art" và "Truyện cười" (toàn bộ tiếng Việt). Chạy ngay bằng Python chuẩn (không cần cài thêm thư viện).

Hướng dẫn nhanh:
1. Tải zip từ: https://github.com/fireantmarketing11-wq/vui-desktop-vn/archive/refs/heads/main.zip
2. Giải nén, mở terminal trong thư mục vừa giải nén.
3. Chạy: python main.py

Yêu cầu: Python 3.10+ (hoặc 3.8/3.9 thường cũng OK). Tkinter là một phần của stdlib; trên một số hệ bạn cần cài gói tkinter (ví dụ apt install python3-tk trên Debian/Ubuntu).

Nội dung thư mục:
- main.py: file khởi chạy
- app/: module chính chứa GUI và logic
- data/: dữ liệu mẫu (truyện cười và mẫu emoji)
- LICENSE, README.md, requirements.txt

Nếu bạn muốn tôi tạo file .exe cho Windows hoặc thêm tính năng, nói mình biết.
